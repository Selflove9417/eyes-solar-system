它会汉化什么

3D 场景标签

太阳、行星、卫星、彗星、小行星与航天器的悬浮名称。官方实现把这些渲染成普通页面元素，改写后不会被程序回写。

菜单与分类

主菜单、分类标题、精选专题、搜索提示、“最受欢迎”天体推荐等。

详情面板

Info / Toolbox / View Options 三个标签、简介区块标题、相关条目与外部专题标记。

右侧工具条

全部控制按钮的悬停提示，如“显示信息面板”“切换图层”“放大”“切换光照模式”等。

时间轴控制器

LIVE、真实速率、展开/收起、暂停播放、提高/降低速率等提示。日期与时间数值保持原样。

新手引导与对话框

引导文案、全部嵌入选项标签及其说明文字。按键字母保留原文。

它不会改动

  • NASA / JPL 标识与 Eyes on the Solar System 产品名——按品牌规范保留。
  • 任何数字：日期、时间、距离、坐标、单位换算值。
  • WebGL 画面本身（行星、环系、轨道线、尾迹、星空）。扩展不接触 3D 画布。
  • 官方实体库中没有可靠中文译名的条目——保留英文，不硬造译名。

安装步骤

Chrome 浏览器（桌面端）

  1. 下载并解压上方 eyes-zh-extension.zip 离线包。
  2. 在地址栏输入 chrome://extensions 并按回车，开启右上角开发者模式。
  3. 点击加载已解压的扩展程序，选择解压出的 dist/eyes-zh-extension 文件夹。
  4. 访问 NASA Eyes 官方站点，界面与天体标签即可显示为中文。

Edge 浏览器（桌面端）

  1. 同样先下载并解压 eyes-zh-extension.zip 离线包。
  2. 在地址栏输入 edge://extensions 并按回车，开启左下角开发人员模式。
  3. 点击加载解压缩的扩展，选择解压出的 dist/eyes-zh-extension 文件夹。

为什么不能一键安装：Chrome 与 Edge 浏览器安全机制规定本地扩展需通过开发者模式“加载已解压的扩展程序”，无法由第三方网站直接静默安装。这是浏览器的安全隔离设计。

卸载与恢复

在 chrome://extensions 或 edge://extensions 管理页面中点击“移除”即可彻底删除，不留任何本地残留；官方站点即可恢复原始英文呈现。

已知限制与边界说明

  • 官方改版：汉化层依赖官方界面 class 名与英文字面量。官方更新界面后可能出现漏译，需要同步更新术语映射。
  • 动态模板：官方文案含有运行时变量占位符，替换发生在渲染阶段，个别句子可能出现中英混排。
  • 长尾名称：在官方 700+ 实体中，仅已建立可靠中文审定对照的条目会被汉化，其余条目严格保留英文。
  • 本站嵌入视窗内不适用：扩展直接作用于顶层官方页面；本站 3D 探索页里的嵌入视窗受浏览器同源安全策略保护，不直接受扩展影响。
