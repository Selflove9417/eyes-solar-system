  • NASA / JPL 标识与 Eyes on the Solar System 产品名——按品牌规范保留。
  • 任何数字：日期、时间、距离、坐标、单位换算值。

安装步骤

Chrome 浏览器（桌面端）

  1. 下载并解压上方 eyes-zh-extension.zip 离线包。
  2. 在地址栏输入 chrome://extensions 并按回车，开启右上角开发者模式。
  3. 点击加载已解压的扩展程序，选择解压出的 dist/eyes-zh-extension 文件夹。
  4. 访问 NASA Eyes 官方站点，界面与天体标签即可显示为中文。

Edge 浏览器（桌面端）

  1. 同样先下载并解压 eyes-zh-extension.zip 离线包。
  2. 在地址栏输入 edge://extensions 并按回车，开启左下角开发人员模式。
  3. 点击加载解压缩的扩展，选择解压出的 dist/eyes-zh-extension 文件夹。

为什么不能一键安装：Chrome 与 Edge 浏览器安全机制规定本地扩展需通过开发者模式“加载已解压的扩展程序”，无法由第三方网站直接静默安装。这是浏览器的安全隔离设计。

卸载与恢复

在 chrome://extensions 或 edge://extensions 管理页面中点击“移除”即可彻底删除，不留任何本地残留；官方站点即可恢复原始英文呈现。

已知限制与注意事项

  • 界面随官方更新：它只替换界面文字，不改动画面本身。若 NASA 官方改版或新增未收录功能，可能出现部分文字保持英文，我们会随版本跟进补齐。
  • 混合拼接句子：包含动态变化数值（如倒计时、实时距离）的句子，部分前缀可能呈现中英混排。
  • 长尾天体：官方 700 多个天体中，仅已有公认中文审定译名的条目会被汉化，尚未建立权威中文译名的罕见条目严格保留英文。
  • 作用范围说明：扩展专为直接在浏览器访问 NASA 官方网站时设计；本站内嵌的 3D 漫游视窗受浏览器底层安全隔离保护，不直接受此扩展改动。
查看扩展底层技术实现与安全细节

DOM 监听与文本替换：扩展利用 MutationObserver 监听界面节点变化，根据官方界面 class 选择器与英文字面量匹配中文字典进行局部注入，不会中断官方 WebGL 渲染管线。

动态模板占位符：部分文本含有运行时变量占位符（如 {days} days ago），由于替换发生在客户端渲染阶段，无法预知的模板字面量会做保守处理，优先保障程序稳定性。

跨域与同源安全隔离：根据浏览器同源安全策略（Same-Origin Policy），主站无法注入跨域 iframe 内部。因此本站探索页视窗仍由官方英文原生驱动，扩展仅在用户直接打开 eyes.nasa.gov 顶级页面时生效。
