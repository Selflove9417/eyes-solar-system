中文汉化扩展

这是唯一能把 NASA 模拟器自身界面汉化的途径——因为它运行在你自己的浏览器里，作用在官方页面的 DOM 上，而不是隔着跨域 iframe。

扩展只读取、只改文字。 它不采集也不上传任何数据，不申请任何主机权限以外的能力，只在 eyes.nasa.gov/apps/solar-system/ 上运行； 不下载、不缓存、不重新分发 NASA 的任何程序或素材。3D 计算与画面完全由官方站点产生。

它会汉化什么

3D 场景标签

太阳、行星、卫星、彗星、小行星与航天器的悬浮名称。官方实现把这些渲染成普通 DOM 元素，因此可以替换；实测改写后不会被应用回写。

菜单与分类

主菜单、分类标题、精选专题、搜索提示、"最受欢迎"等。

详情面板

Info / Toolbox / View Options 三个标签、简介区块标题、相关条目与外部专题标记。

右侧工具条

全部图标的悬停提示（aria-label），如"显示信息面板""切换图层""放大""切换光照模式"等。

时间轴

LIVE、真实速率、展开/收起、暂停播放、提高/降低速率等提示。日期与时间数值不变。

新手引导与嵌入对话框

引导文案、全部嵌入选项标签及其说明文字。按键字母保留原文。

它不会改动

  • NASA / JPL 标识与 Eyes on the Solar System 产品名——按品牌规范保留。
  • 任何数字：日期、时间、距离、坐标、单位换算值。
  • WebGL 画面本身（行星、环系、轨道线、尾迹、星空）。扩展不接触 canvas。
  • 官方实体库中没有可靠中文译名的条目——保留英文，不硬造译名。

安装步骤

Chrome（桌面）

  1. 下载并解压上方 eyes-zh-extension.zip 压缩包（或在本地源码目录执行 node tools/pack-extension.mjs）。
  2. 地址栏打开 chrome://extensions，开启右上角开发者模式。
  3. 点加载已解压的扩展程序，选择 dist/eyes-zh-extension 文件夹。
  4. 访问 官方站点，标签与界面即为中文。

Edge（桌面）

  1. 同样先下载并解压 eyes-zh-extension.zip 离线包。
  2. 地址栏打开 edge://extensions，开启左下角开发人员模式。
  3. 点加载解压缩的扩展，选择 dist/eyes-zh-extension 文件夹。

为什么不能一键安装：Chrome 与 Edge 只允许从各自商店直接安装扩展，本地开发的扩展必须走"加载已解压"。 这是浏览器的安全设计，无法由网站绕过。

卸载

在 chrome://extensions 或 edge://extensions 中移除即可，不留任何残留；官方站点恢复原样。

已知失效场景

  • 官方改版。汉化依赖 .pioneer-label-div 等 class 名与英文字面量。NASA 更新界面后可能出现漏译，需要更新 data/ui.zh.json。
  • 动态模板。官方文案含 ##moon_count## 一类占位符，替换时机在渲染阶段，个别句子可能出现中英混排。
  • 长尾名称。451 条卫星与 169 条航天器中，只有已建立对照的部分会被汉化，其余保留英文。
  • 本站 iframe 内不适用。扩展作用于顶层页面；3D 探索页里的嵌入窗口不受扩展影响（跨域限制）。
