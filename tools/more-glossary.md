## 1. 基础地貌与行星地质学 (Geology & Terrains)

| `terrain` / `terrains` | **地形** | ❌ 地层（那是 strata） | 用于描述区域地貌特征（如 older, darker terrains） |
| `fracture` / `fractures` | **断裂** / **断裂带** | ❌ 骨折、断片 | 描述冰壳或岩层表面线性裂纹 |

| `crater` / `craters` | **撞击坑** | ❌ 陨石坑 | 天文学规范名词（陨石坑多指坠落地面的残留坑） |
| `mantle` | **地幔** | — | 如 rocky mantle（岩质地幔） |

| `delta` / `deltas` | **三角洲** | — | 火星河流冲积地貌 |
| `lakebed` / `lakebeds` | **湖床** | — | 火星古代干涸湖泊遗迹 |

| `tiger stripes` | **虎纹** | — | 土卫二南极裂缝与断裂构造 |
| `chasmata` | **峡谷群** / **裂谷带** | — | 土卫四、土卫三表面大型深谷系统（如 Ithaca Chasma） |
| `albedo` | **反照率** | — | 表面反射太阳光的能力指标（如土卫八黑白两面） |
| `thermal segregation` | **热分选** | — | 土卫八黑白两面极度反差的热物理驱动机制 |
| `corona` / `coronae` | **冕状物** / **冕状地形** | — | 天卫五表面独特的复杂地貌构造 |
| `fault canyon` / `fault valley` | **断层峡谷** / **断层谷** | — | 天卫五、天卫三表面深裂谷系统 |
| `graben` / `grabens` | **地堑** | — | 天卫一表面以断层为边界的狭长下陷谷地 |
| `trough` / `troughs` | **槽谷** / **槽状地堑** | — | 天卫三表面构造拉张槽谷 |
| `terminator` | **晨昏线** | — | 天体表面受光半球与阴影半球的分界线 |
| `opposition` | **冲** / **冲位** | — | 地外天体与太阳分别位于地球两侧的天象，天卫一亮度在此时显著增亮 |
| `magma ocean` / `magma oceans` | **岩浆洋** | — | 新生月球早期全球熔融岩浆层 |
| `ejecta` / `ejecta deposits` | **撞击溅射物** / **溅射沉积物** | 避免混为“喷出物”（那是火山地质学名词） | 撞击地质学规范用词；亦可称“抛射物”，指撞击坑形成时溅射飞出并堆积的物质 |
| `C-type` | **C 型** | — | 碳质小行星光谱分类，如火卫二表面物质 |
| `oval-shaped` | **椭球形** / **卵形** | — | 描述如妊神星等高速自转天体的不对称形状 |

| `basaltic rock` | **玄武岩** | — | 灶神星表面凝固的基性岩浆岩 |
| `protoplanet` | **原行星** | — | 早期太阳系形成阶段的行星胚胎，如智神星、灶神星 |
| `double-lobed` | **双叶状** | — | 形如雪人的接触双体结构，如阿罗科思 |

| `double dwarf planet` | **双矮行星** | — | 冥王星-冥卫一系统的天文学描述 |
| `mutual tidal locking` | **相互潮汐锁定** | — | 双方始终以同一面相互朝向对方的引力潮汐现象（如冥王星与冥卫一） |

| `planetary defense` | **行星防御** | — | 监测与防止近地天体撞击地球的技术体系与试验领域 |
