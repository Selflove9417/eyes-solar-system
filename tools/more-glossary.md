# NASA Eyes 详情面板长文 (More) 术语对照表 (more-glossary.md)

本项目长文翻译专有术语统一来源。每批翻译前必须先查阅本表，翻译完成后将该批次确认的新术语追加至此，确保全套 92 篇长文用词规范且前后严格一致。

## 1. 基础地貌与行星地质学 (Geology & Terrains)

| 英文原文 | 规范中文译名 | 易错/禁止用词 | 备注与说明 |
| :--- | :--- | :--- | :--- |
| `terrain` / `terrains` | **地形** | ❌ 地层（那是 strata） | 用于描述区域地貌特征（如 older, darker terrains） |
| `fracture` / `fractures` | **断裂** / **断裂带** | ❌ 骨折、断片 | 描述冰壳或岩层表面线性裂纹 |
| `ridge` / `ridges` | **山脊** | ❌ 隆脊 | 表面隆起的线状脊地貌 |
| `groove` / `grooves` | **沟槽** | ❌ 槽、凹槽 | 与 ridges 对应的凹陷纹理 |
| `band` / `bands` | **条纹** / **条带** | ❌ 频段、波段 | 地表冰层颜色/结构条纹 |
| `crater` / `craters` | **撞击坑** | ❌ 陨石坑 | 天文学规范名词（陨石坑多指坠落地面的残留坑） |
| `mantle` | **地幔** | — | 如 rocky mantle（岩质地幔） |
| `core` | **核心** / **地核** | — | 如 iron core（铁质核心） |
| `ice shell` | **冰壳** | — | 外层水冰硬壳 |
| `tectonic plates` | **板块** | ❌ 构造板块 | 如 shifting tectonic plates（板块运动） |
| `ring` / `rings` | **环** | ❌ 光环 | 统一定为“环”（如木星环、土星环），不用“光环” |
| `river valley networks` | **河谷网络** | — | 火星古代水流冲刷遗迹 |
| `delta` / `deltas` | **三角洲** | — | 火星河流冲积地貌 |
| `lakebed` / `lakebeds` | **湖床** | — | 火星古代干涸湖泊遗迹 |
| `equatorial ridge` | **赤道脊** | ❌ 赤道山脉（除非特指） | 土卫八赤道独特隆起山脊地貌 |
| `hydrothermal vent` / `vents` | **热液喷口** | — | 土卫二海底热液喷口 |
| `tiger stripes` | **虎纹** | — | 土卫二南极裂缝与断裂构造 |
| `chasmata` | **峡谷群** / **裂谷带** | — | 土卫四、土卫三表面大型深谷系统（如 Ithaca Chasma） |
| `albedo` | **反照率** | — | 表面反射太阳光的能力指标（如土卫八黑白两面） |
| `thermal segregation` | **热分选** | — | 土卫八黑白两面极度反差的热物理驱动机制 |

## 2. 天体动力学与物理现象 (Dynamics & Physics)

| 英文原文 | 规范中文译名 | 易错/禁止用词 | 备注与说明 |
| :--- | :--- | :--- | :--- |
| `tidal forces` | **潮汐力** | ❌ 潮水力 | 引力梯度引起的摄动力 |
| `aurora` / `auroras` | **极光** | — | 带电粒子激发的发光现象 |
| `perturb` / `perturbation` | **摄动** | ❌ 扰动、捣乱 | 天体力学标准术语 |
| `magnetic lines of force` | **磁力线** | — | 行星磁场力线 |
| `electric generator` | **发电机** | — | 木卫一洛伦兹力感应发电效应 |
| `Great Red Spot` | **大红斑** | — | 木星标志性反气旋风暴 |
| `gas giant` | **气态巨行星** | ❌ 气体行星 | 木星、土星分类标准术语 |
| `ice giant` | **冰巨行星** | ❌ 冰态巨行星 | 天王星、海王星分类标准术语 |
| `solar wind` | **太阳风** | — | 太阳向外喷射的高能带电粒子流 |
| `regolith` | **风化层** | ❌ 土壤（除非特指地球生物土壤） | 天体表层细颗粒风化物 |
| `axial tilt` | **轴倾角** | ❌ 轴倾斜度 | 自转轴与公转轨道法线夹角 |
| `runaway greenhouse effect` | **失控温室效应** | — | 金星极端温室效应标准术语 |
| `tidally locked` | **潮汐锁定** | — | 卫星自转与公转周期同步，始终以同一面朝向母星 |
| `plume` / `plumes` | **羽流** / **喷羽** | ❌ 喷气 | 土卫二南极冰下海洋喷向太空的水汽和冰粒柱 |
| `eccentric orbit` | **偏心轨道** | — | 非正圆轨道，离心率大于 0 |
| `tidal heating` | **潮汐加热** | — | 轨道偏心与引力摄动引起的内部摩擦与潮汐形变加热 |
